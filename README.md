# Weather App 🌤️

A clean, responsive, card-based Weather Forecast web application built with vanilla JavaScript, HTML5, and CSS3. The application fetches real-time weather data using the OpenWeatherMap API.

---

## Features

- **City Search**: Query weather data for any city worldwide.
- **Current Metrics**: Displays real-time temperature (Celsius), weather condition description, and humidity levels.
- **Card UI**: Modern, centered card interface with clean typography and smooth interactions.
- **Error Handling**: Graceful error feedback for invalid city names or network issues.

---

## Tech Stack

- **HTML5**: Semantic document structure.
- **CSS3**: Responsive flexbox layout and modern styling.
- **JavaScript (ES6+)**: DOM manipulation and Fetch API for asynchronous HTTP requests.
- **OpenWeatherMap API**: Live weather data provider.
